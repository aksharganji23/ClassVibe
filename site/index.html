Install in 4 steps

  1. Tap Download APK above (on your phone).
  2. Open the downloaded ClassVibe-….apk from notifications or the Downloads app.
  3. If asked, allow Install unknown apps for your browser or Files app.
  4. If Play Protect warns about an unknown developer, tap More details → Install anyway. ClassVibe updates itself from GitHub after that.
